# ⛵ YachtJet

A modern and responsive landing page for a luxury yacht rental service.

The project focuses on creating an elegant user interface with clean structure, responsive design, and reusable CSS architecture.

---

## 🚀 Live Demo

🔗 https://vl-as.github.io/yachtjet/

---

## ✨ Features

- 📱 Fully responsive design
- ⚓ Modern yacht rental landing page
- 🎨 Clean and structured CSS architecture
- 🧩 Section-based page organization
- ✨ Interactive UI elements
- 📐 Adaptive layout for different screen sizes
